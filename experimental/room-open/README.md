# Windows 방 검색·열기 실험

정확한 이름으로 방을 검색하고, 확인한 검색 행을 열어 창 상태를 점검합니다. 사용자가 대화창을 미리 열어둘 필요는 없지만 **검색·열기 순간에 카카오톡을 잠시 전면으로 가져옵니다.** 메시지·파일·사진 전송, 클립보드, 로그인·보안·확인 옵션 변경은 없습니다. 모든 결과에서 `send_ready=false`, `actual_send=NOT_RUN`을 유지합니다.

방 제목과 창 구조를 확인하는 도구입니다. 방 ID와 전송 대상 창을 연결하는 외부 계약을 제공하지 않습니다. 일반 방 발신 기능은 없으며, 방이 열렸다는 결과를 실제 전달 성공으로 표시하면 안 됩니다. 실물 원본과 공개 이식본의 확인 범위는 [QA 기록](../../docs/room-opening-QA.md)에 구분했습니다.

## 준비

- Windows x64, Python3.11 이상 x64, 지원 KakaoTalk **26.8.2.5324 x64**가 필요합니다. 실제 원본 검증은 Python3.14에서 했습니다.
- 본인이 로그인한 대화형 데스크톱에서 카카오톡이 실행 중이어야 합니다. 잠금·로그아웃·GUI 없는 서버 실행을 지원하지 않습니다.
- 검색·열기에는 카카오톡 메인 창이 표시된 상태여야 합니다. 트레이에 숨긴 메인 창은 자동으로 꺼내지 않으며 `MAIN_NOT_UNIQUE`로 차단할 수 있습니다. 모달 창·중복 창·다른 앱 버전도 차단합니다. 자동으로 로그인하거나 설정을 고치지 않습니다. 읽기 전용 `check`는 메인 창의 표시 여부와 별개로 이미 열린 대화창을 검사합니다.
- 전체 저장소를 내려받아 그 폴더에서 실행합니다. 기본 스킬 설치기는 이 실험 디렉터리를 복사하지 않습니다. 이 폴더만 따로 복사하면 읽기 모듈을 찾을 수 없습니다.

```powershell
git clone https://github.com/aixlife/kakaotalk-automation.git
cd kakaotalk-automation
python -m venv .venv
$python = (Resolve-Path '.venv\Scripts\python.exe').Path
& $python -m pip install -r requirements-windows.txt
& $python experimental/room-open/room_open.py inspect
```

이미 저장소와 가상환경이 있다면 다시 만들지 않고 해당 Python을 사용합니다. `inspect`는 메인 창과 컨트롤을 읽기 전용으로 확인하며 방을 열거나 검색하지 않습니다. `--help`로 명령을 볼 수 있습니다.

## 검색 결과를 확인하고 열기

아래 이름은 가상 예제입니다. 본인이 접근할 수 있는 방의 정확한 이름으로 바꿉니다. `--allow-ui`는 이번 검색의 전면 전환과 검색어 입력을 명시적으로 허용합니다. 실행하는 짧은 동안 키보드·마우스를 함께 조작하지 않습니다.

```powershell
& $python experimental/room-open/room_open.py search --name "가상 프로젝트 논의방" --allow-ui
```

기존 검색어가 있으면 자동으로 덮어쓰지 않습니다. 현재 검색어를 대체하려는 경우에만 같은 명령에 `--replace-search`를 추가합니다. 검색어는 메인 검색 Edit에만 지정하며 대화 입력칸에는 쓰지 않습니다.

성공 응답의 `receipt_path`는 저장된 검색 영수증, `capture_path`는 검색 결과 영역만 담은 로컬 BMP입니다. 캡처에는 최근 메시지 미리보기가 포함될 수 있으므로 로컬에서만 확인합니다. `result.snapshot.capture`에는 이미지 크기와 `bounds`가 있으며, `bounds`는 `[왼쪽, 위, 오른쪽, 아래]` 화면 좌표입니다.

1. 검색이 성공하고 전면·커서 복구가 확인된 영수증인지 확인합니다.
2. BMP를 원본 크기로 확인하고 정확한 방 이름의 행을 찾습니다. 같은 이름의 후보가 여럿이거나 잘려 구분되지 않으면 열지 않습니다.
3. 이미지 안에서 행의 안전한 중앙 위치 `(image_x, image_y)`를 고릅니다. 화면 좌표는 `X = bounds[0] + image_x`, `Y = bounds[1] + image_y`입니다. 임의의 예제 좌표나 첫 행을 그대로 쓰지 않습니다.
4. 검색 후 **300초 이내**에 아래 명령을 실행합니다. `SEARCH_RECEIPT_PATH`, `X`, `Y`를 실제 값으로 바꿉니다.

```powershell
& $python experimental/room-open/room_open.py open --search-receipt "SEARCH_RECEIPT_PATH" --point X Y --confirm-row --allow-ui
```

`--confirm-row`는 사람이거나 화면을 확인할 수 있는 에이전트가 정확한 행을 검토했다는 뜻입니다. 이름만 보고 자동으로 이 옵션을 붙이지 않습니다. 다른 에이전트에 맡길 때에도 로컬 캡처 확인이 필요하며, 개인 대화 미리보기를 공개 서비스나 Issue로 옮기지 않습니다.

열기 직전 PID·생성시각·창/컨트롤·검색어·좌표·유효시간·검색 결과 캡처를 다시 확인합니다. 결과가 바뀌었거나 화면이 가려졌으면 클릭하지 않습니다. 클릭 뒤에는 정확한 창 제목과 입력칸·메시지 목록 구조를 확인합니다. 이 검사는 제목이 같은 방의 고유 ID까지 증명하지 않습니다.

## 열린 뒤 배경 점검

```powershell
& $python experimental/room-open/room_open.py check --name "가상 프로젝트 논의방"
& $python experimental/room-open/room_open.py check --name "가상 프로젝트 논의방" --check-preview
```

`check`는 전면 전환·마우스·키보드 입력 없이 정확한 제목의 창, 입력칸/메시지 목록 수, 빈 입력칸 또는 안내 문구, 표시·활성·비최소화 상태를 검사합니다. `--check-preview`는 첨부 확인 옵션의 실제 적용 상태를 읽기 전용으로 추가 확인합니다. 옵션을 켜거나 끄지 않습니다. 이 확인은 전송 가능 인증이나 실제 발신 시험이 아닙니다.

## 화면에 남는 변화와 오류 처리

검색·열기 후 원래 전면 창과 커서로 복귀를 시도하고 실제 값을 검사합니다. **검색어와 열린 대화창은 남습니다.** 방을 열면 카카오톡의 읽음 상태 등이 달라질 수 있으므로 열 권한이 있는 방만 선택합니다. 명령 중 다른 앱을 조작하거나 Windows가 전면 전환을 거부하면 `BLOCKED`로 끝날 수 있습니다.

복귀 실패·시간 초과·통신 단절 때는 일부 UI 동작이 이미 실행됐을 수 있습니다. 성공 응답을 못 받았다는 이유로 `open`을 반복하지 않습니다. 먼저 저장된 영수증과 읽기 전용 `inspect`/`check`로 현재 상태를 확인합니다. `UI_OUTCOME_UNKNOWN_NO_RETRY`는 결과를 확정할 수 없다는 뜻이며 성공·미실행 어느 쪽으로도 해석하지 않습니다. 새 검색이 필요하면 현재 상태를 확인하고 새 영수증을 만들어 다시 행을 검토합니다.

검색 영수증 하나로 `open`을 실행할 수 있는 횟수는1회입니다. 시간 초과나 복귀 실패여도 사용 기록은 남으며, 같은 영수증을 다시 주면 `SEARCH_ALREADY_CLAIMED_NO_RETRY`로 차단합니다. 결과 파일은 저장·동기화 후 공개하고, 저장 실패 시 별도 비상 영수증을 시도합니다. 비상 영수증이나 저장 실패 결과는 열기용 검색 증거로 받아들이지 않습니다.

## 저장·동시 실행·자원 제한

요청·결과 영수증과 제한된 검색 캡처는 `%LOCALAPPDATA%\KakaoReader\room-open`에 저장합니다. 방 이름·창 정보·미리보기가 포함될 수 있으므로 공유·Git 추가를 하지 않습니다. 저장소 밖에 보관하며 자동 삭제하지 않습니다. 캡처는 검색 목록 영역만, 최대1024×768·3MiB입니다. 전체 데스크톱 캡처는 하지 않습니다.

새 명령은 자기방 QA와 같은 `%LOCALAPPDATA%\KakaoReader\self-attachment-qa\serial.lock` 잠금을 사용합니다. 잠금을 얻지 못하면 대기열을 만들거나 동시에 실행하지 않고 중단합니다. 잠금 파일을 지워 다른 작업을 우회하지 않습니다.

작업 Job은256MiB·17초, 코어는11.5초 소프트 한도·14.5초 하드 한도를 유지합니다. 카카오톡 관측 private memory가469,893,120B 이상이면 중단하며 앱 메모리 설정이나 앱 자체를 변경하지 않습니다. 강제 시간 종료 시 복구 코드도 끝나지 못할 수 있으므로 영수증과 현재 상태를 확인해야 합니다.

미지원 버전·권한·세션·해시·자원 가드를 해제해 실행하지 않습니다. 관리자 권한, 디버그 권한, 앱 주입, 보안 옵션 변경은 이 도구의 준비 절차가 아닙니다.
