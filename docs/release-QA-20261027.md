# 공개 패키지 검증 범위

검증일: 2026-10-27. 기본 설치는 읽기 전용 스킬이며 세 실험 도구는 저장소에서 별도로 실행합니다.

## v0.2.0 방 열기 실험 추가

| 대상 | 결과 | 한계 |
|---|---|---|
| macOS 합성 검사 | Python3.14에서97개 PASS, Python 소스33개 구문 검사 | 앱 데이터 접근0 |
| Windows 합성 검사 | Python3.14에서97개 중92개 PASS·5개 SKIP, 실패0 | 기본 권한으로 심볼릭 링크를 만들 수 없어 기존 설치기 관련5개 건너뜀. 같은5개는 macOS에서 PASS |
| 방 열기 안전 검사 | 신규33개 모두 두 플랫폼에서 PASS | 모의 결과·가상 자료로 재실행, 변경 캡처, 복구 실패, 저장 실패를 검증 |
| Windows 공개 패키지 복사 | 소스52개 SHA-256 일치 | 사용자별 로컬 경로, 기존 공개 읽기 런타임 사용 |
| 실제 `inspect`·`search` | `MAIN_NOT_UNIQUE`로 입력 전에 차단 | 현재 메인 창이 숨겨진 상태 |
| 실제 일반 방2개 `check` | `TARGET_WINDOW_NOT_FOUND` | 현재 열린 대상 창이 없음 |
| 실제 `open` | NOT_RUN | 공개 이식본의 검색→열기→배경 점검 완주는 미검증 |

실제 네 명령에서 전면·커서가 유지되고 입력·발신0, 결과 영수증 저장을 확인했습니다. 앱 private memory 관측값276,062,208B, 명령 작업 Job최대18,767,872B였습니다. Windows 합성 검사 전체 Job최대50,794,496B,5.373초로256MiB·25초 검사 한도 안에서 끝났습니다. 제품 CLI의 작업 한도는 별도로256MiB·17초입니다. 로그인·화면·보안·첨부 확인 옵션을 변경하지 않았습니다.

첫 Windows 합성 실행은 소스 읽기의 기본 cp949 인코딩과 심볼릭 링크 생성 권한 때문에4개 오류가 났습니다. 소스 검사를 UTF-8로 지정하고, 일반 사용자 계정에서 링크 생성 권한이 없을 때도 파일 리다이렉트 거부 검사를 할 수 있도록 합성 fixture를 수정했습니다. 권한을 추가하거나 제품 가드를 완화하지 않았습니다. 수정 후 위 결과를 다시 확인했습니다.

기존 원본의 두 방 검색·열기·배경 점검 성공은 [방 열기 QA](room-opening-QA.md)에 별도로 보존합니다. 공개판은 한 번 검토한 검색 영수증을 한 번만 소비하며, 시간 초과·저장 실패 뒤의 자동 재시도를 금지합니다. 일반 방 발신, 임의 파일 전송, 수신·완료 응답은 여전히 미검증입니다.

공개 대상은 코드·합성 테스트·익명화한 문서52개입니다. 실제 방 이름·ID·대화·캡처·로컬 영수증·개인 경로·인증 자료는 제외했습니다. LICENSE·README·SECURITY·CONTRIBUTING·제3자 고지·ignore 규칙과 로컬 문서 링크를 검사했습니다.

## v0.1.0 기존 읽기·자기방 실험 기록

| 대상 | 결과 | 한계 |
|---|---|---|
| 합성 회귀 | Python3.14·cryptography47.0.0에서64개 PASS | 실제 송수신을 대신하지 않음 |
| Windows 프로젝트 설치 | dry-run READY →13개 파일 INSTALLED →동일 재설치 UNCHANGED | 기본 읽기 스킬만 설치 |
| 설치 내용 | 세 단계 manifest SHA256 동일 | 전역 설정·보안·로그인 변경 없음 |
| 지정한 일반 방2개 사전검사 | 정확한 방 식별, 창 후보0, 전후 전면·커서 동일 | 전송 준비 완료가 아님 |
| 이식본 자기방 `plan` | `PLAN_BLOCKED_NO_SEND`·발신0 | 당시 자기방 창 조건이 충족되지 않아 PNG 단계 미실행 |
| 이식본 `execute-self-qa` | NOT_RUN | 원본 실행기 성공과 구분 |

Windows 설치 세 단계의 시간은0.323/0.476/0.317초, 최고 Job메모리는14,061,568B였다. 파일 바이트 일치와 재설치 여부를 실제 Windows에서 확인했다. 일반 방 검사 작업의 최고 Job메모리는115,019,776B, 관측 앱 private memory최대366,276,608B로 기존 중단선469,893,120B 아래였다.

이식본 자기방 계획은5.073초·최고123,359,232B로 종료했고 `SELF_WINDOW_SIGNATURE_OR_STATE_CHANGED`를 반환했다. 제한을 풀거나 창을 조작해 통과시키지 않았다. 계획 파일 자체에는 `execute=false`와 발신 승인 없음이 기록된다.

원본 실행기의 자기방 TXT70B·PNG5,931B 실제 송수신·다운로드 해시 일치는 [첨부 QA](attachments-QA.md)에 별도로 기록했다. v0.1.0 검증은 다른 방·임의 파일·닫힌 방 자동 열기·잠금/로그아웃·GUI 없는 서버 실행을 보증하지 않는다. v0.2.0 방 열기 실험의 별도 확인 범위는 위에 기록했다.

검증에 사용한 실제 방 이름·방 ID·대화·영수증·사용자 경로는 배포에 포함하지 않는다. 공개 검사는 가상 자료만 사용한다.
