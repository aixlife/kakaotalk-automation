# 공개 패키지 검증 범위

검증일: 2026-10-27. 기본 설치는 읽기 전용 스킬이며 두 실험 도구는 저장소에서 별도로 실행합니다.

| 대상 | 결과 | 한계 |
|---|---|---|
| 합성 회귀 | Python3.14·cryptography47.0.0에서64개 PASS | 실제 송수신을 대신하지 않음 |
| Windows 프로젝트 설치 | dry-run READY →13개 파일 INSTALLED →동일 재설치 UNCHANGED | 기본 읽기 스킬만 설치 |
| 설치 내용 | 세 단계 manifest SHA256 동일 | 전역 설정·보안·로그인 변경 없음 |
| 지정한 일반 방2개 사전검사 | 정확한 방 식별, 창 후보0, 전후 전면·커서 동일 | 전송 준비 완료가 아님 |
| 이식본 자기방 `plan` | `PLAN_BLOCKED_NO_SEND`·발신0 | 당시 자기방 창 조건이 충족되지 않아 PNG 단계 미실행 |
| 이식본 `execute-self-qa` | NOT_RUN | 원본 실행기 성공과 구분 |

Windows 설치 세 단계의 시간은0.323/0.476/0.317초, 최고 Job메모리는14,061,568B였다. 파일 바이트 일치와 재설치 여부를 실제 Windows에서 확인했다. 일반 방 검사 작업의 최고 Job메모리는115,019,776B, 관측 앱 private memory최대366,276,608B로 기존 중단선469,893,120B 아래였다.

이식본 자기방 계획은5.073초·최고123,359,232B로 종료했고 `SELF_WINDOW_SIGNATURE_OR_STATE_CHANGED`를 반환했다. 제한을 풀거나 창을 조작해 통과시키지 않았다. 계획 파일 자체에는 `execute=false`와 발신 승인 없음이 기록된다.

원본 실행기의 자기방 TXT70B·PNG5,931B 실제 송수신·다운로드 해시 일치는 [첨부 QA](attachments-QA.md)에 별도로 기록했다. 새 공개 패키지의 다른 방·임의 파일·닫힌 방 자동 열기·잠금/로그아웃·GUI 없는 서버 실행을 보증하지 않는다.

검증에 사용한 실제 방 이름·방 ID·대화·영수증·사용자 경로는 배포에 포함하지 않는다. 공개 검사는 가상 자료만 사용한다.
