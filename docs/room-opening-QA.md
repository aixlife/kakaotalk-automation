# 방 검색·열기 검증 범위

검증일: 2026-10-27. 지원 설치본은 KakaoTalk26.8.2.5324 x64이며, 기존 원본 실물 검증은 Windows의 로그인된 대화형 세션과 Python3.14에서 수행했습니다. 실제 방 이름·방 ID·창 핸들·대화·캡처·원본 영수증은 공개하지 않습니다.

## 확인된 기능의 경계

| 작업 | 확인 범위 |
|---|---|
| 닫힌 채팅창의 대화 읽기 | 기존 읽기 CLI에서 화면 조작 없이 실물 확인. [읽기 QA](QA.md) 참조 |
| 방 검색·열기 | 기존 원본으로 지정한 일반 방2개를 검색하고 정확한 행을 확인해 열기 성공 |
| 열린 뒤 배경 점검 | 두 창의 제목·구조·빈 입력칸/안내 문구·표시/활성·비최소화 상태 확인 |
| 첨부 확인 옵션 | 실제 적용값 OFF를 읽기 전용으로 확인. 설정 변경0 |
| 최종 전면·커서 | 원래 상태로 복구 후 배경 검사 전후 동일 |
| 메시지·파일·사진 발신 | 이번 방 열기 시험에서 모두0건 |
| 일반 방 전송 계약 | 미검증. `send_ready=false`, `actual_send=NOT_RUN` |

원본의 최종 판정은 `PASS_TWO_ROOMS_OPENED_THEN_BACKGROUND_PRECHECK_NO_SEND`입니다. 창이 없는 상태에서 단순 배경 검사만 했을 때는 `TARGET_WINDOW_NOT_FOUND`였고, 이후 명시적으로 허용된 화면 검색·열기를 사용해 두 창을 열었습니다. **앱이나 로그인된 데스크톱 없이 동작하는 완전 헤드리스 발신을 확인한 결과가 아닙니다.**

일반 방 ID, 파일/접근권, 완료 응답을 받는 정식 외부 호출의 연결은 확인하지 못했습니다. 과거 고정 자기방 TXT·PNG 성공은 [첨부 QA](attachments-QA.md)에 별도로 기록했으며 일반 방·임의 파일 전송 증거로 사용하지 않습니다.

## 원본 실물 시험의 실패와 보완

검색 초기에 전역 `Ctrl+A`가 검색어 선택 대신 친구 추가 단축키로 처리되는 문제가 있었습니다. 빈 창을 확인한 뒤 취소했고 친구 등록·메시지 입력은 없었습니다. 이후 정확히 확인한 메인 검색 Edit에만 검색어를 지정하도록 바꿨습니다.

일부 실행에서 원래 전면 창 복귀가 거부돼 성공으로 표시하지 않았습니다. 임시 입력 큐 연결을 해제하는 복귀 처리를 보완하고 최종 상태를 다시 확인했습니다. 한 방은 실제로 열린 후 창 열거 한도에서 결과 확인이 막혔습니다. 클릭을 반복하지 않고 기존 한도인 최상위500·자식2000개 안에서 읽기 전용으로 재확인했습니다.

최종 기록에서 앱 private memory 관측최대367,329,280B, 작업 Job최대21,118,976B였습니다. 앱 중단선469,893,120B와 작업256MiB를 유지했고 잔존 작업0개를 확인했습니다. 이 수치는 해당 원본 시험의 측정값이며 모든 환경의 최대 사용량을 뜻하지 않습니다.

## 공개 이식본의 검증

원본을 별도 [방 열기 CLI](../experimental/room-open/README.md)로 분리하고, 개인 PC 경로 대신 사용자별 로컬 상태 폴더를 사용합니다. 화면 조작은 `--allow-ui`, 행 확인은 `--confirm-row`로 명시하며 실패한 검색 영수증·오래된 영수증·변경된 검색 결과는 열기에 사용하지 않습니다. 코어 제한과 공통 잠금, 발신 없는 동작 범위를 유지합니다.

공개 이식본을 Windows에서 실행한 결과, 현재 메인 창이 숨겨진 상태여서 `inspect`와 `search`가 `MAIN_NOT_UNIQUE`로 차단됐습니다. 두 지정 방의 `check`는 `TARGET_WINDOW_NOT_FOUND`로 종료했습니다. 네 명령 모두 전면·커서가 유지됐고 입력·발신0, 영수증 저장을 확인했습니다. 메인 창을 꺼내거나 로그인·보안 설정을 변경하지 않았습니다.

따라서 공개 이식본의 실제 검색→열기→배경 점검 완주는 **미검증**이며 `open`은 실행하지 않았습니다. 원본의 두 방 성공을 이식본 성공으로 대체하지 않습니다. 이번 릴리스는 기존 읽기 기능에 방 열기 **실험 도구**를 추가한 사전 릴리스입니다. 합성 검사와 공개 패키지 검증 결과는 [릴리스 QA](release-QA-20261027.md)에 기록합니다.

검증하지 않은 범위는 다른 KakaoTalk 빌드, 모든 Windows 세션·배율·테마·모니터 조합, 동명이 있는 모든 방, 잠금/로그아웃·GUI 없는 서버, 일반 방 발신과 실제 수신·완료 응답입니다. 원본의 성공 조건을 모든 계정·환경에 대한 보장으로 확대하지 않습니다.
